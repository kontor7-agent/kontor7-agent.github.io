FAQ

Is my file uploaded anywhere?

No. The file is read locally by your browser and processed on your own device. There are no network requests, and the cleaned file is created in your browser when you click download.

How does it decide that two rows are duplicates?

Rows are duplicates when all the key columns you ticked hold the same value. Tick every column to find fully identical rows, or only one column such as an email address or invoice number to find repeated records that differ elsewhere.

Which row is kept in the cleaned file?

The first occurrence in the file is kept and later matches are dropped. The original order of the remaining rows is preserved. If the later row is the better one, sort your file first and run it again.

Does it handle semicolons, tabs and quoted fields?

Yes. Comma, semicolon and tab delimiters are detected automatically from the start of the file, and you can override the choice. Quoted values containing the delimiter, doubled quotes or line breaks are read correctly and written back with proper quoting.

Why are ' Smith' and 'smith' treated as the same?

By default the tool ignores spaces around values and upper/lower case, since these are common causes of hidden duplicates. Untick those options if differences in spacing or capitalisation should count as distinct values.

Is there a size limit?

The tool reads up to 50,000 data rows to keep your browser responsive. If your file is longer, a message tells you, and the download contains only the rows that were read. Split very large files into parts first.
